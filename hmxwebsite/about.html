About the project

A focused Android app, built in the open.

HMXPDF is an independent open-source document toolkit for Android. The source is public, the core work runs on your device, and the website separates what the app does from what it does not.

What HMXPDF is

HMXPDF is an Android application for everyday document work: reading and annotating PDFs, filling forms, signing, organizing pages, scanning paper, editing Word and Excel documents, cleaning up images, and creating PDFs. It is built with Kotlin and Jetpack Compose and licensed under the MIT License.

The app is designed around a few clear ideas: keep document processing local, group tools by the job you are doing, and state the limits instead of pretending every format has full desktop-editor parity.

What this website is

This is the official information, download, privacy, and support website for the Android app. It is a static site built with HTML, Tailwind CSS, and vanilla JavaScript. It does not include a browser-based editor, user accounts, a dashboard, a database, or any other second version of the product.

Project status

The project is actively developed in the public repository. The current source version is 2.1.1 (versionCode 6) and supports Android 6.0 (API 23) or newer. Source version numbers are not release announcements: the Download page reads GitHub Releases and shows whether an APK is actually published.

How the builds differ

The GitHub APK is the FOSS distribution. It can download the optional LibreOffice-based Office engine on request and can convert a web address you enter to PDF. The Play build keeps the same application identity but delivers the optional engine through Play Feature Delivery. See the privacy policy for the resulting network differences.

Open source and attribution

HMXPDF is licensed under the MIT License. Third-party components retain their own licenses and notices. The app relies on work from the Android open-source community and the following projects, among others:

  • PdfBox-Android by Tom Roush for PDF operations (Apache-2.0).
  • Apache POI for Office document handling (Apache-2.0).
  • AndroidLiquidGlass by Kyant0 for backdrop and glass effects (Apache-2.0).
  • Tesseract4Android and Tesseract OCR for the on-device OCR fallback (Apache-2.0).
  • LibreOffice, via the optional LibreOffice Lite engine build, for Office rendering (MPL-2.0). The engine is not bundled in the GitHub APKs.
  • Google Play services and ML Kit for the document scanner, text recognition, and subject segmentation components.

Support and contact

The project does not publish a company address, support email, or social accounts. Bug reports, feature requests, privacy questions, and security coordination go through the official GitHub issue tracker. See Support for what to include.
