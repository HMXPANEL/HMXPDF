Support

Report it where the code lives. GitHub Issues.

HMXPDF does not publish a support email address or run a help desk. Bug reports, feature requests, and privacy questions go through the official public issue tracker.

Bugs and crashes

Use the issue tracker with reproduction steps, app version, Android version, device model, and the distribution you installed.

What to include

Feature requests

Describe the workflow you need and why the existing tools are insufficient. Concrete examples help more than a one-line request.

Privacy and security

Ask privacy questions on the tracker. For a security issue, do not publish exploit details or private files; request a private channel first.

Security guidance

Before you post

A useful bug report

Check the FAQ and search existing issues first. Then include:

  • 1. HMXPDF version from Settings → About, and the versionCode if shown.
  • 2. Android version and device model.
  • 3. Which build you installed: GitHub APK, F-Droid, or Play.
  • 4. Exact steps to reproduce, including the file type and size.
  • 5. What you expected and what happened instead.
  • 6. Whether the optional Office engine was installed.
  • 7. A screenshot or short screen recording with private content removed.

Security reports

Do not open a public issue containing exploit details, private documents, personal information, access tokens, or signing keys. If the official repository offers private vulnerability reporting, use that channel. Otherwise, open a minimal public issue asking for a private way to contact the maintainers, without disclosing the vulnerability.

Include the affected version or commit, the impact, and reproduction steps once a private channel is available. Allow reasonable time for verification and a fix before public disclosure.

Install help

Common install problems

“App not installed”

An existing copy may be signed with a different key, or the APK may target a different ABI. Installing a build from a different source can require uninstalling the old one. Uninstalling removes app-private recents, signatures, checkpoints, and settings, so export anything you need first.

“Unknown apps” blocked

Android requires you to allow installs from the browser or file manager you used. Enable it only for that app, install the official APK, then turn it off again if you prefer.

Play Protect warning

Sideloaded APKs can trigger a Play Protect warning. Confirm the file came from the official GitHub release and verify its SHA-256 before choosing to install.

Wrong architecture

If a release publishes ABI-split APKs, the filename usually says arm64-v8a, armeabi-v7a, x86, or universal. Use the universal package if you are unsure.

No release shown

The Download page reads GitHub directly. If the panel reports that no APK is published, check the releases page again later; this website does not host builds.

Scanner or OCR unavailable

These features can depend on Google Play services and the device. Without the required components, the specific feature may not be available; the rest of the app is unaffected.

Support expectations

This is a community open-source project. Reports and contributions are handled when maintainers or contributors are available; there is no guaranteed response time or commercial support contract.

The project does not publish a support email address, phone number, or private dashboard.
