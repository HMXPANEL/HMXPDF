Privacy Policy

What HMXPDF stores, sends, and never collects.

Last updated: 17 November 2026

This policy describes the HMXPDF Android application and this website. It is based on the app's public source code and documentation. Distribution variants can differ, so the relevant differences are called out below.

The short version

  • No account, no ads, no analytics SDK, no crash-reporting service in the app code.
  • No HMXPDF server for uploading documents or extracted text.
  • Document work runs on your device.
  • Some optional features use the network: the Office engine download, web-address to PDF, and Google Play services components.

1. Scope

This policy covers the HMXPDF Android app (package com.hmx.pdf) and the static website that presents it. It does not cover third-party apps or websites you choose to open, share with, or download from.

HMXPDF is an independent open-source project. The app's source code is available at github.com/HMXPANEL/HMXPDF, and this policy reflects the behaviour implemented there. If a future build changes that behaviour, this page will be updated.

2. Data collection

HMXPDF does not require an account and does not operate a document-upload service. Based on the app code, it does not include:

  • an account, sign-in, profile, or cloud sync system;
  • in-app advertising or an advertising SDK;
  • a product analytics SDK;
  • a crash-reporting service such as Crashlytics or Sentry;
  • a server that receives your documents, extracted text, signatures, or usage history.

The app does not ask for your name, email address, phone number, contacts, location, or microphone access. Settings and document state are kept locally as described below.

3. What is stored on your device

HMXPDF writes app state and working files to storage controlled by Android. The following items are created by the app:

Item What it contains Where and how long
Recent files File URI, display name, timestamps, page count, reading progress, and pin state. App-private preferences. The list is normally capped at 20 entries, with pinned entries kept. You can turn it off in Settings; turning it off clears the history.
Local document copies Private copies of documents opened from other apps, so Recents can reopen them after a temporary URI grant expires. App-specific storage. Enabled by default; you can disable "keep local document copies" in Settings, which clears the copies.
Editor checkpoints Unsaved edits for a document, used to recover after the app process is closed. noBackupFilesDir/editor-checkpoints. Replaced per document and cleared after a successful save or when you discard recovery.
Save recovery journals Temporary data used to recover a manual save that was interrupted. noBackupFilesDir/save_recovery. Removed when the save completes or recovery is discarded.
Signatures PNG images of signatures you save. filesDir/signatures. Kept until you delete the signature or uninstall the app.
Settings Theme, language, save location, feature toggles, and similar preferences. App-private preferences. Kept until you change them, clear app data, or uninstall.
Exported files PDFs, images, Office files, and other outputs you choose to save or share. The location you pick, normally Download/HMXPDF or a folder chosen through Android's file picker. These files remain until you delete them.
Temporary caches Decrypted PDF pages, shared export staging files, and conversion intermediates. App cache or temporary directories. Cleared by the app or Android; excluded from backups where they may contain plaintext.

Document content stays local unless you explicitly share or export it. HMXPDF does not upload it to the project.

4. Permissions

The app manifests declare the following Android permissions:

Permission Why it is used
CAMERA Document scanning. Camera hardware is declared optional; other features work without it.
READ_EXTERNAL_STORAGE (Android 12L and lower) Reading documents you select on older Android versions.
WRITE_EXTERNAL_STORAGE (Android 9 and lower) Saving exports to shared storage on older Android versions.
POST_NOTIFICATIONS Showing progress or completion notifications for longer document operations. Denying it does not stop the core work.
FOREGROUND_SERVICE, FOREGROUND_SERVICE_DATA_SYNC Keeping long-running document work alive while it completes.
INTERNET, ACCESS_NETWORK_STATE Declared by the FOSS and F-Droid builds for the optional Office engine download and web-address to PDF. The base Play manifest does not declare INTERNET, although merged libraries can contribute permissions; the Play build delivers the optional engine through Play Feature Delivery.

Android's document picker (Storage Access Framework) lets you grant access to specific files and folders without giving the app broad access to your storage.

5. Network communication

HMXPDF is not fully offline in every build. Most PDF, spreadsheet, image, and local-document processing runs on the device, but the following features can make network requests:

Optional Office engine (FOSS build)

In Settings you can request the optional LibreOffice-based engine. The app downloads a pinned archive from a GitHub release, checks the archive's expected size and SHA-256 before installing it, and then converts documents locally in an isolated app process. GitHub receives the normal request information that any download sends, such as your IP address and user agent.

Web address to PDF (FOSS build)

When you enter a web address to convert, the app requests that address and the page resources it loads. Those requests go to the website you chose, not to an HMXPDF document-processing server. That website may receive your IP address and other standard request data under its own privacy policy.

Google Play services

The document scanner is provided by Google Play services. Background removal uses ML Kit subject segmentation, whose model may be delivered by Google Play services. Google manages those service and model downloads under its own terms and privacy policy. Document processing remains on the device.

Play Feature Delivery

The Play build can deliver the optional Office engine as an on-demand feature module through Google Play. That delivery is handled by Google Play, not by an HMXPDF server.

Sharing and opening files

When you share or export a file, Android passes it to the app or destination you choose. That recipient handles the file under its own privacy practices. HMXPDF does not control what another app does with a file you intentionally send to it.

6. Third-party services and components

HMXPDF does not sell personal data or share it with advertisers or analytics providers. The third-party interactions that can occur are limited to the features above:

  • GitHub hosts the source code, releases, APK downloads, and the optional Office engine archive. A download request is sent to GitHub.
  • Google Play services provides scanning and may provide ML Kit model components used for OCR or background removal.
  • LibreOffice is the upstream project for the optional Office engine. The engine runs locally after download.
  • The website you choose receives requests when you use web-address to PDF.
  • Android and other installed apps receive files only when you use the system share, open, print, or save flows.

HMXPDF is not affiliated with Google, Microsoft, or The Document Foundation. Their trademarks and services remain subject to their own terms.

7. Retention and deletion

  • Recent files: clear them in Settings, or turn off "remember recent files". The list is normally capped at 20 entries, with pinned entries kept.
  • Local document copies: turn off "keep local document copies" to clear them, or clear Recents.
  • Checkpoints and save recovery: normally cleared after a successful save or when you discard a recovery prompt.
  • Signatures: delete a saved signature in the app. Uninstalling the app also removes the app-private signature files.
  • Exports: files saved to Download/HMXPDF or another folder are outside the app's private storage. Delete them with your file manager.
  • Uninstall: removing HMXPDF deletes its app-private data and app-specific storage. It does not delete documents you saved elsewhere or copies another app has received.

Because the project does not operate a server that stores your documents or account data, there is no server-side copy to request for deletion.

8. Android backups

The app allows Android backup (allowBackup="true"). Depending on your device and backup settings, Android may include some app data in cloud or device-to-device backups. The app excludes plaintext document caches, save-recovery journals, and other sensitive working files from backup through its backup rules. You can disable app backups in Android's system settings.

9. This website

This website is a static site. It does not use cookies, analytics, advertising, third-party fonts, or a contact form. It does not ask you to create an account.

The Download page requests the public GitHub Releases API directly from your browser so it can show the current release. That request is sent to GitHub, which receives normal request information such as your IP address. The page works without that request; if GitHub is unreachable, it links you to the releases page instead.

10. Children

HMXPDF is a general-purpose document tool and is not directed to children under 13. It does not require an account and does not knowingly collect personal information from children. Documents you open remain under your control.

11. Security

The app relies on Android's app sandbox and app-private storage for local data. It does not upload documents to an HMXPDF service. No storage or transmission method is perfectly secure, so keep backups of important documents and install APKs only from the official repository.

For security reports, follow the guidance on the Support page. Do not post private documents, personal data, or access tokens in a public issue.

12. Changes to this policy

This policy may be updated when app behaviour or distribution changes. The date at the top of the page shows the latest revision. Material changes will be reflected here before or when the related build is distributed.

13. Contact

For privacy questions about HMXPDF, open an issue in the official repository: HMXPDF issue tracker. The project does not publish a separate privacy email address.

Please do not include private documents, personal information, or credentials in a public issue.
