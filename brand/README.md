# HMXPDF brand assets

`hmxpdf-logo.png` is the official HMXPDF logo supplied by the project owner.
It is a 1254 × 1254 PNG: a rounded deep-navy square with the document mark and
the HMXPDF wordmark, on a white background.

The icon variants use the master artwork with transparent outer corners where appropriate.
The adaptive foreground uses the document mark from the master.

- Android launcher icons and adaptive-icon foregrounds (`app/src/main/res`,
  `android_icon/res`)
- Website navbar, footer, favicon, Apple touch icon and web manifest icons
  (`hmxwebsite/assets/img`)
- Open Graph / social preview and store graphics (`hmxwebsite/assets/img`,
  `screenshots`, `fastlane/metadata/android/en-US/images`)

Do not edit the generated icons by hand. Change the master and regenerate the
derived sizes so every location stays consistent.
