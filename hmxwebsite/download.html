      Verify the file

      Check the SHA-256 yourself

      Compare GitHub’s published SHA-256 with the hash you compute locally after downloading. Replace filename.apk with the downloaded filename in these commands.

      Windows PowerShell

      Get-FileHash .\filename.apk -Algorithm SHA256

      macOS

      shasum -a 256 filename.apk

      Linux

      sha256sum filename.apk

      A matching hash shows the file is the same one GitHub published. If GitHub did not publish a digest, this website does not invent one.

      Install

      Installing an APK

      1. 1 Download the APK for your device from GitHub and verify its SHA-256.
      2. 2 If Android asks, allow your browser or file manager to install unknown apps. Only do this for a file you trust.
      3. 3 Open the downloaded APK for your device and confirm the install. Use the universal APK if unsure.
      4. 4 Turn off the install-unknown-apps permission again if you enabled it.

      Only install APKs from the official repository. This website does not mirror files, and no third-party download counter or rating is displayed here.

      Which APK file?

      If a release publishes ABI-split APKs, the filename usually includes the supported architecture:

      • arm64-v8a — most modern phones and tablets
      • armeabi-v7a — older 32-bit ARM devices
      • x86_64 / x86 — emulators and x86 devices
      • universal — larger package with all supported ABIs

      These suffixes describe the build configuration. Only the assets that appear in the release panel are actually published.
