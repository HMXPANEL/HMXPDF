All images in this folder are genuine captures of the HMXPDF application or
derivatives of the official website artwork. No screenshot was fabricated,
re-rendered, or edited to show functionality the app does not have.

[`docs/media/screenshots/`](../docs/media/screenshots/); this folder keeps the
same captures together with the promotional assets.

## What was removed

The following inherited assets contained the previous product name or the
upstream repository URL and were deleted from the current tree (they remain in
Git history):

- `banner_gh.png` — artwork said **ClearPDF** and linked `github.com/Chethan616/ClearPDF`.
- `social_preview_1280x640.png` — same ClearPDF artwork.
- `light home screen.jpg`, `dark home screen.jpg`, `light pdf tools.jpg`,
  `dark pdf tools.jpg`, `light settings screen.jpg`, `dark settings screen.jpg`,
  `docx editing.jpg`, `xlsx editing.jpg` — screenshots whose title pill read
  **ClearPDF**.

They were replaced by the clean captures listed above. Nothing was invented: a
replacement exists only where a genuine clean capture already existed.

## GitHub social preview

GitHub does not expose an API for the repository social preview image. Upload
`social-preview.png` manually in **Settings → General → Social preview**.
